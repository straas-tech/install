STRAAS CLI

AI-powered development workflows for engineering teams.

Install (macOS & Linux)
curl -fsSL https://straas-tech.github.io/install/cli.sh | bash

Requires: curl, bash. Installs to /usr/local/bin/straas (or ~/.local/bin/straas if not writable).


Pin a version: curl -fsSL https://straas-tech.github.io/install/cli.sh | bash -s -- v0.2.0


Custom install dir: STRAAS_INSTALL_DIR=$HOME/bin curl -fsSL https://straas-tech.github.io/install/cli.sh | bash
